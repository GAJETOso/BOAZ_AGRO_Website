# BOAZ AGRO LIMITED Website

A premium, institutional digital presence for **BOAZ AGRO LIMITED**, a global agricultural conglomerate.

## Features
- **Modern Institutional Design**: Built with a focus on "Agri-Luxury" aesthetics using Deep Emerald and Metallic Gold.
- **10 Core Business Divisions**: Showcasing Large-scale Farming, Livestock, Agro-processing, AgriTech, and more.
- **Live Commodity Dashboard**: Real-time simulation of agricultural commodity prices.
- **Investor Portal**: Secure-access simulation for corporate governance and financial reporting.
- **Responsive & Interactive**: Fully responsive design with scroll-reveal animations and glassmorphic UI elements.

## Tech Stack
- **HTML5**: Semantic structure for SEO and accessibility.
- **CSS3**: Vanilla CSS with custom variables and modern layout techniques (Grid/Flexbox).
- **JavaScript**: Vanilla JS for interactions, modal management, and live data simulation.
- **Assets**: Custom AI-generated high-resolution imagery.

## Directory Structure
- `index.html`: Main entry point.
- `styles.css`: Core design system and component styles.
- `hero_bg.png`: Hero section imagery.
- `about_image.png`: Corporate profile imagery.
- `agritech_preview.png`: AgriTech platform visualization.

## Deployment
This project is designed to be hosted on GitHub Pages or any static web hosting service.
